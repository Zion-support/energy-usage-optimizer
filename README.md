# Energy Usage Optimizer

> Cut facility energy spend with AI

Analyzes meter and IoT consumption data, tariff windows and equipment schedules to shift loads, flag waste and negotiate better rates.

**Live:** https://ziontechgroup.com/energy-usage-optimizer/  
**Network hub:** https://github.com/Zion-support/zion-app-network

## Features
- Interval-meter and IoT ingestion with anomaly detection
- Peak-demand and tariff-window load shifting recommendations
- Equipment schedule optimization with savings forecasts
- Monthly energy-waste report with prioritized actions
